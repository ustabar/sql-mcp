🚀 VsCode ve Github Copilot ile SQL Sorgu Asistanı 📊

Son zamanlarda Model Context Protocol (MCP) üzerinde kafa patlatırken, 
Github Copilot ile Türkçe doğal dil desteği sunan bir sorgu asistanı 
nasıl oluşturabilirim diye düşünüyordum. MCP server ile bunun mümkün olduğunu gördüm. 

Geliştirdiğim çözüm, veritabanı sorguları oluşturmayı herkes için kolay hale getirirken (herhangi bir SQL komutu bilmeden "ne vereceksin abine" tarzında sorular ile) başka bir ortama gerek duymadan doğrudan Github Copilot Chat üzerinden veritabanındaki veriyi sorgulamayı mümkün kılmakta.


## 📌 Projenin Temel Özellikleri:

- Github Copilot a yapacağı işi Prompt dosyası ile tanımlama

- Türkçe sorular ile veritabanındaki bilgileri sorgulayabilme

- Sorulara verilen yanıtların JSON formatında dönme

- Azure SQL veritabanı ile entegrasyon

- Sorgu sonucunda gelen verilerinin Gİthub Copilot ile değerlendirilmesi


## 💻 Teknik Detaylar:

- Proje .NET 9 ile geliştirildi

- Github Copilot Agent Mode ve Claude 3.7 Sonnet modeli kullanıldı

- Vs Code ve MCP Server entegrasyonundan yararlanıldı


## 🔌 VS Code ve GitHub Copilot Entegrasyonu:

- Öncelikle MCP server oluşturma için https://lnkd.in/dMEUQdHp
 adresindeki rehber uygulama ile projenin çatısı oluşturuldu

- MCP server olarak oluşturulan ilk projeye Tool özelliği eklendi

- GitHub Copilot Agent Mode ekranında, oluşturulan MCP Server Vs Code a tanıtıldı. Bunun için settings içerisine MCP Server tanımı eklendi


Bu yöntem ile, veritabanı sorgularını teknik bilgiye sahip olmayan kullanıcılar için de kolaylaştıran bir çözüm ortaya çıkarmış olduk. 

Soruları Türkçe soruyorsunuz, Github Copilot bunu SQL komutuna dönüştürüyor ve sonucu Chat ekranında görebiliyorsunuz.

Aslında bir yerde "Stay in the flow - Akışta kal" prensibini hayata geçirmiş oluyorsunuz. Dilerseniz uygulamayı diğer veritabanı çözümlerine de (Postgres, Cosmos, Prometheus, Elastic, Log Analytics Workspace, ve diğerleri) uygulayabilirsiniz.
